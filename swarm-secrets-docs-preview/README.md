# Swarm Secrets documentation preview

Companion documentation for Dokploy/dokploy#5943, proposed at Dokploy/dokploy#5942.

The screenshots show the locally built production docs with the existing website layout and components. Names in the stack example are sample names. No secret content or private test state is included.

See verification.json and browser-results.json for validation commands and results. The UI feature has separate evidence under swarm-secrets-preview.
